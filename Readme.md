# 📚 Online Book Store Database (MySQL)

A comprehensive MySQL database project that simulates an online bookstore using the Goodreads Books dataset (20,000+ books).

## Features

- Relational Database Design
- Database Normalization (3NF)
- Advanced SQL Queries
- Views
- Stored Procedures
- Triggers
- Transactions
- Window Functions
- Common Table Expressions (CTEs)

## Dataset

- Goodreads Books Dataset (20,000+ books)

## Tech Stack

- MySQL
- MySQL Workbench
